# UnblockedTDM Roadmap to 2.0

- 1.3 v1 — Match Core: 3v3 roster, round state machine, scoring, timers, sudden death, first-to-five structure, side swaps, directional dash.
- 1.4 v1 — Bots / Team Combat: full AI movement, aiming, weapon use, target selection, respawning and team behavior.
- 1.5 v1 — Spawn / Flow / Minimap: final spawn safety, minimap, firing reveals, dead-player handling and flow cleanup.
- 1.6 v1 — HUD / Menus / Settings: complete match HUD, settings, keybinds, graphics/audio options and HUD customization.
- 1.7 v1 — Loadouts / Persistence: 25 saved loadouts, between-round changes, settings persistence and update-safe migrations.
- 1.8 v1 — Postgame / Stats: results screen, K/D/A, damage, streaks, criticals, duration, rematch and main-menu flow.
- 1.9 v1 — Feature Complete Playable: full-game validation, balance and edge-case fixes. This is the first feature-complete playable version.
- 2.0 — Big Polish Update: graphics, animation, map art, UI transitions, audio/SFX, performance, presentation, onboarding and launcher polish.
