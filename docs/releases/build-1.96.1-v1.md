# Skirmish Arena 1.96.1 — Phase 4

Phase 4 focuses on fullscreen-first presentation, input convenience, and game audio while preserving the Phase 2 menu hierarchy and Phase 3 Tactical HUD.

## Added

- Fullscreen-first game launch while preserving the F11 and Settings fullscreen toggle.
- Auto Sprint setting, enabled by default and persisted locally.
- Game Audio toggle, enabled by default.
- Master Volume setting, defaulting to 75%.
- Procedural Web Audio profiles for Assault Rifle, SMG, Sniper, Shotgun, LMG, Pistol, Launcher, and Melee.
- Reload, shell insertion, weapon-swap, dry-fire, footstep, explosion, and UI interaction audio.
- Distance attenuation and stereo positioning for world audio.
- Responsive fullscreen scaling for the main menu, loadouts, settings, pause UI, match HUD, scoreboard, and tactical map.

## Preserved

- Phase 2 menu structure and working click controller.
- Phase 3 Tactical HUD, TAB scoreboard, kill feed, MVP ranking, and M tactical map.
- Existing weapon stats and damage values.
- Existing movement, sprint stamina, dash, AI, spawn, map, and match rules.
- Existing launcher/update workflow and compatibility paths.
