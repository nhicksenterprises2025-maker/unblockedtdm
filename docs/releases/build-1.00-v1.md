# UnblockedTDM Build 1.00 — Version 1

This is the first UnblockedTDM pre-development distribution build.

## Included
- Windows installer and uninstaller foundation.
- Dedicated UnblockedTDM Launcher.
- Separate UnblockedTDM game executable shell.
- Per-user game install data so updates do not overwrite player data.
- GitHub-backed update checks.
- Safe staging, SHA-256 verification, backup, and rollback for game updates.
- Version Archive with independent downloads of previous game builds.
- Repair Game verification/re-download flow.
- Launcher settings persistence.
- GitHub Actions Windows packaging and immutable release publishing pipeline.

## Gameplay
Gameplay systems are intentionally not part of this pre-development build. The purpose of this build is to establish the permanent launcher, installer, update, archive, and release architecture that future UnblockedTDM builds will update in place.
