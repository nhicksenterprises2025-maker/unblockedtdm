# Skirmish Arena 2.01.3

2.01.3 corrects the 2.01.2 menu-scroll scope and rebuilds Loadouts as a true one-page screen.

## Main Menu
- Restored normal main-menu scrolling when content exceeds the viewport.
- Removed the 2.01.2 global Weapon Info scroll lock from the main content area.
- Weapon Info keeps the real in-game crosshair spread preview introduced in 2.01.2.

## Loadouts
- Loadouts now fit inside a single viewport with no vertical page scrolling.
- Compressed the loadout header, saved-slot strip, slot controls and footer.
- Rebalanced the weapon list and weapon-detail columns to use the available screen space.
- Kept the real gameplay weapon models from 2.01.1.
- Kept the real gameplay crosshair spread previews from 2.01.2.
- Compact short-screen rules keep the page usable at lower vertical resolutions.

## Compatibility / Scope
- No weapon damage, spread, accuracy, recoil or fire-rate changes.
- No movement, AI, map, spawn, collision or match-rule changes.
- Launcher/update behavior is unchanged.
