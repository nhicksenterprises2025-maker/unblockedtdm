# Skirmish Arena Launcher 1.0.1

This is a launcher-only branding refresh for the existing Skirmish Arena launcher.

## Changes
- Replaces visible UnblockedTDM launcher branding with Skirmish Arena.
- Keeps the existing launcher visual style and Skirmish Arena logo.
- Renames the Windows app to Skirmish Arena Launcher.
- Renames the desktop and Start Menu shortcut to Skirmish Arena.
- Renames the Windows uninstall entry to Skirmish Arena Launcher.
- Ships as `SkirmishArena-Setup-1.0.1.exe`.
- Preserves the existing launcher app identity and launcher data directory so current settings, game installation state and archived builds remain available.
- Keeps legacy internal game executable names only where required for update compatibility.

## Bundled game
The installer bundles the immutable Skirmish Arena 1.99.3 Final Release Candidate. It does not publish or install the unfinished 2.0 prototype.
