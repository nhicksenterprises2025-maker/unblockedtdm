# Skirmish Arena 2.01.2

Weapon Info presentation update focused on spread readability and one-page usability.

## In-Game Crosshair Spread
- Replaced the old wedge-style spread graphic with the actual gameplay crosshair renderer.
- Added Base, Moving and ADS crosshair previews using each weapon's canonical spread values.
- Crosshair shape, gap scaling and ADS behavior now match the live in-match reticle.

## One-Page Weapon Info
- Rebuilt Weapon Info to fit inside the available viewport without vertical scrolling.
- Compressed the weapon header, model stage, stat bars and detailed stat grid while preserving all information.
- All eight weapon selector rows fit inside the Weapon Info screen without an inner scrollbar.

## Scope
- Weapon spread values are unchanged.
- ADS accuracy is unchanged.
- Damage, fire rate, movement, recoil, AI, map geometry, spawns and match rules are unchanged.
