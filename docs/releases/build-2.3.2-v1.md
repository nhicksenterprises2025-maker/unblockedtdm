# Skirmish Arena 2.3.2 — Build 1

## Home Command Deck Cleanup

2.3.2 is a deliberately small presentation update on top of the stable 2.3.1 Build 2 boot-integrity foundation.

### Home screen

- Removes the three tutorial-style summary cards from Home:
  - 3V3 · FIRST TO 5
  - 25 SAVED SLOTS
  - 4 DIFFICULTIES
- Career remains the next major information block below the hero.
- Keeps the supplied metallic Skirmish Arena hero logo.
- Keeps the silver Play command treatment, real in-game weapon Loadouts art, silver Settings gear and existing Quit presentation.

### Weapon Info command art

- Simplifies the Weapon Info tile icon.
- Keeps the requested blue manual / gun-sketch identity while removing extra blueprint decoration, gradient detail and auxiliary marks.
- The dedicated all-eight Weapon Info catalog itself is unchanged in this update.

### Stability contract

- No startup/bootstrap changes.
- No Career changes.
- No Loadouts behavior changes.
- No HUD/gameplay changes.
- No weapon balance changes.
- The packaged Windows EXE must still pass the deterministic boot smoke gate before release publication.

- 2.3.4: in-match HUD visual refactor and dash stamina separation.
