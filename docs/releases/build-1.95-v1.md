# Skirmish Arena 1.95 — Phase 3

Phase 3 adds the tactical in-match HUD layer while preserving the Phase 2 front end and all canonical gameplay balance.

## Tactical HUD
- Added a live TAB scoreboard with Kills, Deaths, Assists, K/D and Damage for all six players.
- Added Top 3 performer presentation with #1 identified as MVP.
- Added a live kill feed showing killer, weapon and victim.
- Critical eliminations are highlighted and labeled CRITICAL.
- Added M tactical map for Training Complex.
- Tactical map uses white for the local player, blue for teammates and red only for tactically revealed enemies.
- Enemy reveal behavior remains limited to 1.5 seconds after enemy fire.
- Existing Health, Stamina, Dash, Ammo, Weapon, Timer, Kills and Round Wins HUD information is retained and presented as part of the tactical match interface.

## Compatibility / Scope
- Phase 2 menu structure and working click controller are unchanged.
- No weapon stats or weapon balance changed.
- No movement, sprint, dash, AI, spawn, map geometry or match-rule values changed.
- The public launcher/update path remains the same main workflow.
